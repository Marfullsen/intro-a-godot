Clase 1: Creando mi personaje

Vamos a imaginar un personaje, y le pediremos a la IA que genere un sprite.

Vamos a calzar los sprites de movimiento, reposo, y acción.

Instalamos Godot, y abrimos el ejecutable

Vamos a crear un nuevo proyecto, le daremos un nombre y clickeamos crear.

Se tomará unos segundos en iniciar...

Vamos a darle un vistazo al entorno de Godot 4, clickeando e investigando

Vamos a cargar las imágenes de los sprites al proyecto.

Primero vamos a ubicar la carpeta del proyecto.

Veremos los archivos por defecto de la carpeta

Pegaremos ahí la carpeta con todo nuestro arte, de la carpeta *art*

Confirmamos que aparece la carpeta art.

Crear Nodo del jugador, subir las animaciones, y crear colisiones

Creamos un node tipo other

Buscamos Area2D, seleccionamos Area2D, y le damos click a crear.

Si lo lograste verás el objeto creado.

Para que sea más entendible, lo renombraremos a "Jugador" (con mayúscula en la primera letra siguiendo las convenciones)

¡Perfecto! Tenemos una especie de "DIV" (como si fuera HTML), un espacio en blanco donde irá nuestro personaje.

Ahora necesitamos un objeto que muestre las animaciones.

Crearemos un objeto tipo AnimatedSprite2D

Click derecho en "Jugador", crearemos un nodo hijo.

Buscamos AnimatedSprite2D, seleccionamos y le damos a crear.

Una vez creado debiera verse así.

Al costado derecho deberíamos ver un panel de inspección, con las opciones para agregar las animaciones.

Al hacer click en "Sprite Frames" veremos un panel para agregar animaciones.

Renombraremos la animación "default" por "caminar" y hacemos click en el ícono de la carpeta.

El ícono de la carpeta nos desplegará una galería de imágenes disponibles.

Manteniendo la tecla CTRL presionada, iremos seleccionando las imágenes para la animación de caminar, y hacemos click en Abrir.

Si todo va bien deberías ver algo así:

Aún falta agregar más animaciones, como "Subir".

Creamos una nueva animación usando el botón de crear más animaciones (Es el primer botón con una cruz verde)

Renombramos a "subir", y asignamos las imágenes respectivas.

Ya podríamos ejecutar nuestra primera escena, pero primero debemos guardar los cambios.

CTRL + S para guardar, o el botón de iniciar escena que pedirá guardar la escena.

Confirmamos y dejamos los valores como están, sólo hacemos click en guardar.

En la barra superior derecha veremos los botones para ejecutar.

¡Voilá! Así debiera verse el personaje, aún no hemos configurado movimientos, fondos, sonidos, ni nada, esto recién comienza.

Vamos a definir las teclas de nuestro personaje principal

Arriba en el editor buscaremos la opción del editor del proyecto.

Iremos a Input Bar y iremos agregando las teclas para mover el personaje.

vamos a crear un archivo para pegar el código que moverá al personaje.

jugador.gd
extends Area2D

@export var speed = 400
var screen_size

func _ready():
	screen_size = get_viewport_rect().size

func _process(delta):
	var velocity = Vector2.ZERO
	if Input.is_action_pressed("move_right"):
		velocity.x += 1
	if Input.is_action_pressed("move_left"):
		velocity.x -= 1
	if Input.is_action_pressed("move_down"):
		velocity.y += 1
	if Input.is_action_pressed("move_up"):
		velocity.y -= 1

	if velocity.length() > 0:
		velocity = velocity.normalized() * speed
		$AnimatedSprite2D.play()
	else:
		$AnimatedSprite2D.stop()
	if velocity.x != 0:
		$AnimatedSprite2D.animation = "caminar"
		$AnimatedSprite2D.flip_v = false
		# See the note below about the following boolean assignment.
		$AnimatedSprite2D.flip_h = velocity.x < 0
	elif velocity.y != 0:
		$AnimatedSprite2D.animation = "subir"
		$AnimatedSprite2D.flip_v = velocity.y > 0
	position += velocity * delta
	position = position.clamp(Vector2.ZERO, screen_size)

Y listo, al ejecutar debería moverse por la pantalla.

extends Area2D

signal hit

@export var speed = 400
var screen_size

func _ready():
	screen_size = get_viewport_rect().size

func _process(delta):
	var velocity = Vector2.ZERO
	if Input.is_action_pressed("move_right"):
		velocity.x += 1
	if Input.is_action_pressed("move_left"):
		velocity.x -= 1
	if Input.is_action_pressed("move_down"):
		velocity.y += 1
	if Input.is_action_pressed("move_up"):
		velocity.y -= 1

	if velocity.length() > 0:
		velocity = velocity.normalized() * speed
		$AnimatedSprite2D.play()
	else:
		$AnimatedSprite2D.stop()
	if velocity.x != 0:
		$AnimatedSprite2D.animation = "walk"
		$AnimatedSprite2D.flip_v = false
		# See the note below about the following boolean assignment.
		$AnimatedSprite2D.flip_h = velocity.x < 0
	elif velocity.y != 0:
		$AnimatedSprite2D.animation = "fly"
		$AnimatedSprite2D.flip_v = velocity.y > 0
	position += velocity * delta
	position = position.clamp(Vector2.ZERO, screen_size)

func _on_body_entered(_body):
	hide() # Player disappears after being hit.
	hit.emit()
	# Must be deferred as we can't change physics properties on a physics callback.
	$CollisionShape2D.set_deferred("disabled", true)

func start(pos):
	position = pos
	show()
	$CollisionShape2D.disabled = false

main.gd
extends Node

@export var mob_scene: PackedScene
var score

func _ready():
	new_game()

func game_over():
	$ScoreTimer.stop()
	$MobTimer.stop()

func new_game():
	score = 0
	$Jugador.start($StartPosition.position)
	$StartTimer.start()


func _on_mob_timer_timeout():
	# Create a new instance of the Mob scene.
	var mob = mob_scene.instantiate()

	# Choose a random location on Path2D.
	var mob_spawn_location = $MobPath/MobSpawnLocation
	mob_spawn_location.progress_ratio = randf()

	# Set the mob's position to the random location.
	mob.position = mob_spawn_location.position

	# Set the mob's direction perpendicular to the path direction.
	var direction = mob_spawn_location.rotation + PI / 2

	# Add some randomness to the direction.
	direction += randf_range(-PI / 4, PI / 4)
	mob.rotation = direction

	# Choose the velocity for the mob.
	var velocity = Vector2(randf_range(150.0, 250.0), 0.0)
	mob.linear_velocity = velocity.rotated(direction)

	# Spawn the mob by adding it to the Main scene.
	add_child(mob)


func _on_score_timer_timeout():
	score += 1

func _on_start_timer_timeout():
	$MobTimer.start()
	$ScoreTimer.start()

El código que pegaremos será el siguiente:

info.gd
extends CanvasLayer

# Notifies `Main` node that the button has been pressed
signal start_game

func show_message(text):
	$Mensaje.text = text
	$Mensaje.show()
	$TimerMensaje.start()

func show_game_over():
	show_message("Game Over")
	# Wait until the MessageTimer has counted down.
	await $TimerMensaje.timeout

	$Mensaje.text = "Chispas!"
	$Mensaje.show()
	# Make a one-shot timer and wait for it to finish.
	await get_tree().create_timer(1.0).timeout
	$BotonIniciar.show()

func update_score(score):
	$Puntaje.text = str(score)


func _on_boton_iniciar_pressed() -> void:
	$BotonIniciar.hide()
	start_game.emit()

func _on_timer_mensaje_timeout() -> void:
	$Mensaje.hide()

main.gd
extends Node

@export var mob_scene: PackedScene
var score

func _ready():
	pass

func game_over():
	$ScoreTimer.stop()
	$MobTimer.stop()
	$Info.show_game_over()

func new_game():
	get_tree().call_group("enemigos", "queue_free")
	score = 0
	$Info.update_score(score)
	$Info.show_message("¿Estás listo?")
	$Jugador.start($StartPosition.position)
	$StartTimer.start()
